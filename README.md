## ✨ Funcionalidades

- Design responsivo com tema visual de cibersegurança (matrix rain, cursor customizado, painéis de simulação)
- Animações de entrada e scroll com GSAP + ScrollTrigger
- Seções organizadas: Sobre, Experiência, Skills, Formação, Certificados, Projetos e Contato
- Barras de progresso animadas para habilidades técnicas
- Totalmente construído em HTML, CSS e JavaScript puro — sem frameworks, sem build step

## 🛠️ Tecnologias

- **HTML5** — estrutura semântica
- **CSS3** — variáveis customizadas, grid/flexbox, animações
- **JavaScript (Vanilla)** — interatividade e simulações
- **[GSAP](https://gsap.com/) + ScrollTrigger** — animações de scroll
- **Google Fonts** — Bebas Neue, Orbitron, Barlow, JetBrains Mono

## 🚀 Como rodar localmente

Não há dependências ou build step — basta abrir o arquivo direto no navegador:

```bash
git clone https://github.com/pedrosilvamalheiros/portfolio.git
cd portfolio
```

Depois é só abrir o `index.html` no navegador, ou servir localmente:

```bash
python3 -m http.server 8000
```

E acessar `http://localhost:8000`.
